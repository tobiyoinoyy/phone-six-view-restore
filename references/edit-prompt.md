# 单面编辑提示词

逐项填入实际观察结果，删除不适用行。所有花括号内容必须替换后才调用。

```text
Use case: lighting-weather / precise-object-edit
任务：编辑这台实际使用过的手机的单面照片，消除灯条反射、镜面亮带及打光形成的明显明暗交界，呈现均匀包围式柔和漫射光下的真实材质，同时保留原有瑕疵。不得将其翻新为新机。
输入 1：主编辑原图，{面名，绝对路径}。
输入 2（若有）：同一台手机的{辅助视角}，仅用于{具体位置的重叠证据}，不可改变主图方向与形状。
型号/颜色：{完整型号}，{官方颜色名}。
材质：{有来源支持的边框/前后面材质}；{仅作视觉参考的表面处理}。
视角与画布：沿用主图视角、方向、轮廓、主体比例与完整边缘；{背景/透明要求}。
允许调整：消除{高光具体位置、形状}及{环境染色}；让同一材料区域获得均匀柔光，保留克制的金属光泽与宽而连续的轻微形体渐变；用于后续会添加金属材质光泽的 3D 模型贴图，不能平涂成塑料。不得留下纵向亮带、硬明暗分界或端部聚光斑。真实划痕、露底、天线和贴纸不能作为亮斑抹除。
必须保留的结构：{具体按钮、天线断点、卡槽、端口、孔位、接缝等锚点}。
必须保留的实物瑕疵：{逐项写入编号、位置、走向与交叉关系}。划痕的位置、形状、数量与显眼程度都应与原图尽量一致，不得变淡、加重、移位、增加或重绘成另一套纹理。
不可确定区域：{位置与原因}；高光遮挡且没有可见证据时，仅接续周围金属底色与基础材质纹理，不新增推测性划痕；已确认的纯白高光必须去除。
保留贴纸、污迹、掉色、露底、凹陷、按钮边缘磨损和原有表面纹理。
禁止：美颜、磨皮、补漆、纹理重绘、额外锐化、镜像、修改孔位数量、增减按键、改变机型、照搬官网新机外观、添加文字水印、六宫格、把金属变成塑料、过度消除所有反射。
输出：只有该面手机的一张高保真 PNG 图像。
```

针对性重试：重新附上原图，保留所有约束，只补充“上一候选在 {区域} 出现 {可观察失败}；此次修正 {单项变化}”。不要笼统要求“更高级、更漂亮、更干净”。
